## 💡 The Motto

**DTA** was founded on a simple principle: **Assessment should be instantaneous, distraction-free, and infinitely portable.** 

Traditional examination platforms require heavy database setups, server-side configurations, and complex login funnels that break your momentum. DTA cuts through the noise by delivering a robust, high-performance testing engine that operates entirely within the browser. The goal is to maximize focus, accelerate retention, and give learners an immediate feedback loop without any technical or administrative overhead.

## 🛠️ How to Use It

### Option 1: Run It Online (Recommended)
Simply open the live GitHub Pages link: **[real-debabrata.github.io/DTA/](https://real-debabrata.github.io/DTA/)** to start a test immediately on any desktop, tablet, or mobile device.

### Option 2: Run It Locally
If you prefer to run the application offline or locally from your machine:

1. Locate the downloaded file named `DTA-main.zip` and extract its contents.
2. Open your terminal/command prompt and navigate to the folder:
```bash
   cd DTA-main
```
3. Start a quick local static server to bypass browser file security restrictions (CORS):
```bash
   python -m http.server 8000
```
4. Open your browser and navigate to:
```bash
   http://localhost:8000
```
